    Sync between devices · no cloud · file stays on your devices

    Export an encrypted backup on this PC, copy it to your phone (or the other way), then restore. Each device keeps its own copy — nothing is uploaded.

    How to sync phone ↔ PC
    1. Export a backup here (set a password if you like).
    2. Copy the file via USB, email-to-self, OneDrive, or AirDrop — Steve never sees it.
    3. On the other device open Steve → Sync → Import, pick Merge.

    App lock

    Encrypts everything Steve keeps in this browser (AES-GCM, 256-bit key made from your passphrase with PBKDF2-SHA256, 600,000 rounds). The key only lives in memory while Steve is open. A forgotten passphrase cannot be recovered, so keep a backup file.
